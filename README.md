# Estimating bias in education-specific mortality and educational inequalities in mortality: A scenario-based study
Scenario-based study to evaluate the impact of education misreporting on mortality estimates.

## Instructions
This project uses the renv R package to manage R packages versions. When you start R, the renv package will 
be installed automatically. You whould see a message about this in the console. 

To restore all package versions, please follow these steps:

1.  Install the required packages by running: `renv::restore(promt = FALSE)`.
2.  Verify that all package versions have been restored successfully by running: `renv::status()`
If everything is correct, you should see the message: No issues found -- the project is in a consistent state.
3.  You can now run all scripts in the project.
